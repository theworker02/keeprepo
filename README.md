# keeprepo

Keep URLs and repo query parts with stable normalization.

**Site:** https://theworker02.github.io/keeprepo/

## Install / run

```bash
git clone https://github.com/theworker02/keeprepo.git
cd keeprepo
node src/cli.js
node --test
```
